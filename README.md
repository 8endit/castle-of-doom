# Castle of Doom

A 2D action game built with Phaser.js.

## Play

Open `index.html` in a browser, or visit the live version via GitHub Pages.

## Features

- 3 levels with increasing difficulty
- Multiple enemy types (Chaser, Patrol, Ranged, Boss)
- Combat system with inventory & loot
- Mobile touch controls
- Story intro & win/game-over screens
